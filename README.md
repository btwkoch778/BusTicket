# BusTicket (BMU Travel)

A simple Windows Forms app for booking intercity bus tickets, written in C# (.NET).

## Features

- Choose departure and destination cities, with a button to swap them
- Enter date/time, seat number, and passenger details (name, FIN, phone, email)
- Input validation (same city, past date, FIN length, phone, email, duplicate seat)
- Numbered ticket list with the option to remove a ticket

## Run

1. Clone: `git clone https://github.com/btwkoch778/BusTicket.git`
2. Open `BusTicket.slnx` in Visual Studio 2022 or newer.
3. Press **F5** to build and run.

## Usage

1. Select the **Haradan** (From) and **Haraya** (To) cities.
2. Enter the date and time (e.g. `12/11/2026 14:00`) and the seat (e.g. `6A`).
3. Fill in the passenger information.
4. Click **Bilet al** to add the ticket to the list.
5. To cancel a ticket, select it and click **Siyahıdan sil**.

# BusTicket (BMU Travel)

C# (.NET) ilə yazılmış, şəhərlərarası avtobus biletlərinin sifarişi üçün sadə Windows Forms tətbiqi.

## Xüsusiyyətlər

- Çıxış və təyinat şəhərlərinin seçilməsi, onların yerini dəyişən düymə
- Tarix/saat, yer nömrəsi və sərnişin məlumatlarının (ad, FİN, telefon, email) daxil edilməsi
- Məlumatların yoxlanılması (eyni şəhər, keçmiş tarix, FİN uzunluğu, telefon, email, təkrar yer)
- Nömrələnmiş bilet siyahısı və biletin silinməsi imkanı

## İşə salmaq

1. Klonlayın: `git clone https://github.com/btwkoch778/BusTicket.git`
2. `BusTicket.slnx` faylını Visual Studio 2022 və ya daha yeni versiyada açın.
3. Build edib işə salmaq üçün **F5** basın.

## İstifadə

1. **Haradan** və **Haraya** şəhərlərini seçin.
2. Tarix və saatı (məs. `12/11/2026 14:00`) və yeri (məs. `6A`) daxil edin.
3. Sərnişin məlumatlarını doldurun.
4. Bileti siyahıya əlavə etmək üçün **Bilet al** düyməsinə basın.
5. Bileti ləğv etmək üçün onu seçin və **Siyahıdan sil** düyməsinə basın.
